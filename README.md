# kompas3d-v24-pkgbuild
PKGBUILD для установки КОМПАС-3D Beta на Arch Linux и производные дистибутивы
Возможные проблемы с пакетом:
1. Зависимости. Основные зависимости прописаны в пакете ascon-kompas-graphic-v24, но мне лень переводить зависимости из одной пакетной базы в другую. Debtap выдает неадекватно большой список. В PKGBUILD только те зависимости, которые пришлось доустановить на моей машине.

С пакетом ставится сервер Guardant для програмного ключа защиты. С ним есть 2 проблемы.
1. Сервер ломает "вылеченные от жадности" версии компаса в пределах подсети. Решение - заблокировать порт 3189 на входящие.
2. Сервер может сломаться сам, если при старте сервиса(читай - при загрузке ПК) к ПК подключен внешний жесткий диск. 100% ошибка есть при подключении коробок iodd 2531\zalman ve-300. Решение - отключить диск, systemctl restart grdcontrol, подключить диск обратно.
